这几年我的笔记散落在微信收藏、备忘录、Notion、各种 Markdown 文件里，需要找的时候永远找不到。更糟的是，写在私有笔记里的东西，过一段时间连自己都不愿意回头看——因为知道没人会读，写的时候就已经在敷衍了。

所以我决定搭一个公开的博客。

## 为什么是公开的

写给自己看和写给别人看，是两种完全不同的写作。前者允许跳跃、允许省略、允许"我懂就行"；后者逼着你把逻辑捋顺，把前提交代清楚。

很多我以为想明白的事，一落到要给别人看的文字上，就发现中间缺了环。

这个"发现缺环"的过程，本身就是收获。

## 打算写什么

没有严格的栏目规划，大致是三类：

- **技术笔记**——踩过的坑、解决过的问题。这类内容最大的价值是给未来的自己看
- **阅读与思考**——读到的东西，以及它让我想到什么
- **日常**——一些不值得单独成篇、但又不想丢掉的碎片

不追求日更，也不追求爆款。有想说的就写，没有就让它空着。

## 关于这个站

用 Hugo 生成，托管在 GitHub Pages 上。纯静态，打开快，没有广告，没有弹窗，不收集任何数据。

代码放在 GitHub 上，想改随时能改。整个站点的构建时间不到一秒，所以我可以毫无心理负担地多写几篇。

如果你也想搭一个，流程比我预想的简单——具体步骤我之后会单独写一篇。
